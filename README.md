# Nezflix - Streaming Platform

    *Nezflix is a cutting-edge streaming service designed to bring a wide variety of movies and TV series to audiences globally. This platform allows users to explore, watch, and enjoy content ranging from action-packed series to blockbuster movies and more.

# Features 🎬

    *User Authentication: Secure sign-in and registration system to ensure safe user access and data privacy.
    *Dynamic Content Display: Users can browse through a diverse catalog of movies and series categorized by genre.
    *User Profiles: Customizable user profiles, allowing for personalized content recommendations and settings.
    *Responsive Design: Optimized for a seamless viewing experience across all devices.

# Tech Stack 🔧

    *Frontend: React.js for a dynamic and responsive user interface.
    *Backend: Node.js with Express for robust server-side logic.
    *Database: MySQL for storing user data and content.
    *APIs: Custom APIs for fetching and managing media content.
    *Authentication: Integrated with JWT (JSON Web Tokens) for secure access control.
